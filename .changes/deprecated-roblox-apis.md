`deprecated` flags deprecated Roblox APIs read off `game`, `plugin`, `script`, and `workspace`, such as `workspace:FindPartOnRay`, and deprecated or renamed `Enum` items, such as `Enum.Axis.Left`. The list is generated from Roblox's API dump with `lute run generate-roblox-api`, and messages come from Roblox's creator-docs reference.
